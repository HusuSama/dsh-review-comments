# Third-Party Notices

## PrismJS

This plugin's syntax highlighting is powered by a vendored copy of
[PrismJS](https://prismjs.com) **1.30.0**, included in `src/vendor/prism.min.js`
and bundled into `client.js`. The vendored copy is wrapped in a private scope
(its own `window`/`document`/`global` stubs) and is not exposed to the host page.

Included components: core, clike, markup, css, javascript, jsx, typescript, tsx,
json, markdown, python, bash, yaml, toml, ini, sql, diff, go, rust, java.
